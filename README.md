# SmartPark: Interactive Prototype

A clickable, single-file HTML prototype of **SmartPark**, a campus parking app that shows live garage availability, guides drivers to a spot, and helps them find their car later. It also includes an operations dashboard for parking staff.

## Screens

- **Where are you headed?** Pick a destination (e.g. Woodward Hall)
- **Garages nearby:** live availability and other options
- **Garage detail:** e.g. Union Deck
- **Find my car**
- **Operations dashboard:** the parking-staff view

`user_journey.html` maps the driver's end-to-end journey.

No build step. Open `index.html` or `user_journey.html` in a browser, or enable GitHub Pages on this repo.
